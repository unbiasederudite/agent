# exceptions

The full exception hierarchy, rooted at `AgentError`. `core/` raises only `AgentError` subclasses; adapters catch third-party exceptions at the boundary and re-raise as one of these.

## Contents

- `__init__.py` — `AgentError` (the root), `ConfigError`, `LLMNotFoundError`, `AgentNotFoundError`, `ToolNotFoundError`, `StrategyNotFoundError`, `SessionNotFoundError`, `InputTooLargeError`, `LLMError` (with `LLMRateLimitedError`, `LLMTimeoutError`, `LLMOverloadedError` — raised by the adapter layer when a model's configured `max_concurrent_requests` is already reached, checked before any provider call and never itself retried — `LLMContextWindowExceededError`, and its own subclass `CompactionExhaustedError` — raised only when `AgentRunService`'s compaction-and-retry attempt is exhausted, distinguishing "compaction was tried and could not help" from a plain overflow where compaction was never available to try), `SessionBusyError` — raised by `ISessionStore.busy()` when a second operation targets an `(agent, session_id)` another operation already holds, `RequestTimeoutError` — raised when one `AgentRunService.run()` call exceeds the agent's configured `max_request_seconds`, `ToolNotAllowedError`/`ModelNotAllowedError`/`StrategyNotAllowedError` — raised when a request names a tool/model/strategy that exists but falls outside the agent's own `allowed_tools`/`allowed_models`/`allowed_strategies` ceiling, distinct from the corresponding `*NotFoundError` (not registered at all)
